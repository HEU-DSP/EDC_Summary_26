# Summary_26

2026年电子设计大赛赛后总结仓库，存放成员赛后总结模板。

## 比赛基本信息

- 比赛时间：2026年7月29日 8:00 — 8月1日 20:00（四天三夜）
- 备赛期：不到一个月（7月初 至 7月28日）

## 组织背景（2026年第一次使用该结构，供以后参考）

- 社团分 **算法组** 与 **电子系统组**，分组刚刚确立。实际分工为：
  - **算法组**：承担全部嵌入式软件/代码开发（名为算法组，实为软件组，事实如此）。
  - **电子系统组**：只负责硬件模块的开发、制作与测试。
- 由于系统组不具备软件开发能力、备赛时间短，系统组下设若干小组，每组负责一类**不需要软件**的硬件模块，任务分配时定了进度。
- 算法组几乎没有小组概念，负责人定期给组员布置不同任务（如建立算法库）。
- 比赛期间全组共同完成一道题，最后各小组做差异化设计，避免完全雷同。

## 文件说明

- `赛后总结模板.md` — 成员版，算法组/电子系统组普通成员填写。
- `赛后总结模板-组长版.md` — 组长版，技术组负责人、电子系统组备赛模块小组组长填写，侧重任务分配、进度管理、人员协作的复盘。

## 使用方式

1. 按身份领取对应模板。
2. 按模板填写，填完删除"填写说明"和示例段落。
3. 提交前将文件重命名为 `姓名-赛后总结.md`。
